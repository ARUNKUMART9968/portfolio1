# Arunkumar T portfolio (React + Vite)

## Run it
1. Install Node.js 18 or newer.
2. In this folder run `npm install` (one time).
3. Run `npm run dev` and open the address it prints.
4. Run `npm run build` when you are ready to publish. Upload the `dist` folder to Netlify, Vercel or BigRock.

## Fill in your details
- Links and the Cadence demo sample: `src/data/config.js`
- Put your resume in `public/` and name it `resume.pdf`
- Jokes: `src/data/jokes.js`  |  Toolkit notes: `src/data/toolkit.js`  |  Colour themes: `src/data/themes.js`
- Photos: `src/assets/`

## Folder map
- `src/components/`: one file per section of the page
- `src/data/`: text and settings you edit
- `src/effects/initPortfolio.js`: sound, games, terminal, palette and other interactive behaviour
- `src/styles/global.css`: all the styling
